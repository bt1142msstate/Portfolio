Accessibility

Built to work for more people.

Brandon Temple is committed to providing a portfolio that people can navigate, understand, and use with different devices, input methods, and assistive technologies.

Last reviewed: July 29, 2026

Conformance goal

The portfolio is designed and maintained to conform with the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. The July 29, 2026 self-evaluation found no known Level A or Level AA barriers in the primary portfolio and HTML resume pages.

Accessibility measures

  • Semantic headings, landmarks, lists, links, buttons, and meaningful page titles support structure and navigation.
  • A skip link provides direct access to the main content.
  • All primary navigation, menus, skill details, project galleries, and media dialogs support keyboard operation and visible focus.
  • Dialog focus is contained while a dialog is open and returns to the control that opened it when closed.
  • Images include text alternatives, while decorative graphics are hidden from assistive technology.
  • Text and controls use contrast designed to meet Level AA requirements, with additional support for increased-contrast modes.
  • The layout reflows for desktop, tablet, mobile, and browser zoom without requiring two-dimensional scrolling for primary content.
  • Automatic gallery motion pauses on hover or keyboard focus, includes a pause control, and is disabled when reduced motion is requested.
  • Touch targets meet or exceed the WCAG 2.2 minimum target size.

Technical specifications

Accessibility relies on standards-based HTML, CSS, JavaScript, WAI-ARIA, and SVG. The site is intended to work with current versions of major browsers and the assistive technologies those browsers support.

Assessment approach

The site is assessed through self-evaluation using automated WCAG checks and manual review of keyboard navigation, focus order, dialogs, responsive reflow, reduced motion, image alternatives, document structure, and browser console health on desktop and mobile viewports.

Accessibility is checked again when navigation, content structure, interactive components, or major visual styles change. Automated tools are used as one part of the review, not as a replacement for human evaluation.

Content alternatives and boundaries

Scrollable project captures are supplemental visual demonstrations. Each capture is paired with a meaningful feature title, text description, image alternative, and available live-site or source link.

The downloadable resume PDF is tagged and text-extractable. The same resume information is also available in the HTML resume if that format works better with your assistive technology.

External websites linked from this portfolio are outside Brandon Temple's control and may follow different accessibility practices.

Feedback

If you encounter an accessibility barrier, describe the page, feature, and assistive technology or browser involved when possible. Brandon aims to acknowledge accessibility feedback within five business days and will work toward an accessible alternative or correction.
